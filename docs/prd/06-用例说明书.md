## 6.2 用例详细说明

### UC-001 统一身份认证登录

<!-- widths: 3.0,13.5 -->

| 项目 | 内容 |
| --- | --- |
| 用例编号 | UC-001 |
| 参与者 | 教职工、部门负责人、审批人、领导、文档管理员、系统管理员、审计员；学校统一身份认证（IDP） |
| 优先级 | P0 |
| 关联需求 | FR-AUTH-001、FR-AUTH-003、FR-AUTH-004、FR-AUTH-006 |
| 前置条件 | 用户已在学校统一身份认证中拥有有效账号；OA 已完成认证参数配置 |
| 触发条件 | 用户访问 OA 任意业务页面或点击"统一认证登录" |

**主流程：**

1. 用户访问 OA 页面，系统检测到无有效会话，跳转统一认证登录页并携带回跳地址。
2. 用户在统一认证页完成账号密码或学校要求的认证方式。
3. 认证成功后，IDP 携带票据回跳 OA 回调地址。
4. OA 校验票据，获取学工号、姓名、部门、邮箱等属性。
5. OA 查询本地账号：存在则加载角色、部门、密级与权限版本；不存在则创建"待开通"账号（见 UC-002）。
6. OA 写入会话快照，记录登录日志，跳转回原访问页面。
7. 页面按角色渲染菜单与工作台数据。

**异常与分支：**

- 4a 票据无效或过期：提示"登录已失效，请重新登录"，重新跳转认证，不建立会话。
- 4b IDP 返回缺少学工号：记录错误日志并提示"账号信息不完整，请联系管理员"，不建立会话。
- 5a 账号状态为停用：提示"账号已停用"，记录失败原因，不建立会话。
- 5b 账号状态为待开通：进入待开通提示页，仅可查看提示与联系方式。
- 6a 并发会话超过 3 个：踢出最早会话并提示"已在其他设备登录"。

**后置条件：** 用户会话建立；登录日志写入；权限版本记录到会话。

**业务规则：** 登录失败不区分"账号不存在"与"密码错误"提示；认证过程不记录用户密码；会话 Cookie 必须为 HttpOnly 且按 HTTPS 自动安全标记。

### UC-002 首次登录开通

| 项目 | 内容 |
| --- | --- |
| 用例编号 | UC-002 |
| 参与者 | 教职工、系统管理员 |
| 优先级 | P0 |
| 关联需求 | FR-AUTH-002、FR-SYS-002、FR-SYS-006 |
| 前置条件 | 用户首次通过统一认证，系统中无对应账号 |
| 触发条件 | 首次认证成功 |

**主流程：**

1. 系统创建账号，状态为"待开通"，写入学工号、姓名、部门（无法匹配时为"未分配部门"）。
2. 系统向系统管理员发送"待开通"通知，并在用户列表置顶显示。
3. 管理员核对部门与岗位，选择角色（默认 STAFF，可按岗位追加）与密级权限。
4. 管理员确认开通，账号状态变为"启用"，权限版本自增。
5. 用户重新进入系统，按角色看到工作台。

**异常与分支：**

- 3a 部门无法匹配：管理员先维护部门或选择"未分配部门"，并记录原因。
- 4a 管理员误开通：可在用户管理中停用并重新分配，操作留痕。

**后置条件：** 账号启用；开通记录写入审计日志；用户收到开通通知。

### UC-003 检索与预览文档

| 项目 | 内容 |
| --- | --- |
| 用例编号 | UC-003 |
| 参与者 | 全部内部角色 |
| 优先级 | P0 |
| 关联需求 | FR-DOC-007、FR-DOC-008、FR-DOC-005、FR-DOC-017 |
| 前置条件 | 用户已登录且具备文档查看权限 |
| 触发条件 | 用户在文档中心输入关键词或选择筛选条件 |

**主流程：**

1. 用户输入关键词（标题/编号/标签）或选择分类、部门、密级、时间范围。
2. 系统在权限范围内检索，返回分页结果，展示标题、编号、分类、密级、更新时间。
3. 用户点击文档进入详情，系统二次校验查看权限。
4. 系统展示元数据、当前版本、可见范围摘要与操作时间线。
5. 用户点击"预览"，系统按格式直接预览或转换后预览，并记录预览日志。

**异常与分支：**

- 2a 无匹配结果：提示"未找到相关文档"，建议调整关键词或申请权限。
- 3a 文档已被删除或归档收回：提示"文档不可用"，不展示内容。
- 4a 无下载权限：隐藏下载按钮，接口同样拒绝。
- 5a 转换失败：提示"该格式暂不支持预览，请下载查看"，并提供下载入口（若有权限）。

**后置条件：** 预览行为写入文档操作日志；检索条件可选择保存为视图。

### UC-004 上传文档并提交归档

| 项目 | 内容 |
| --- | --- |
| 用例编号 | UC-004 |
| 参与者 | 教职工、部门负责人、文档管理员 |
| 优先级 | P0 |
| 关联需求 | FR-DOC-002、FR-DOC-004、FR-DOC-010、FR-APR-004、FR-APR-012 |
| 前置条件 | 用户已登录；具备上传权限；目标分类已启用 |
| 触发条件 | 用户点击"上传文档" |

**主流程：**

1. 用户选择文件（或拖拽），系统校验类型、大小与数量。
2. 用户填写标题、分类、标签，选择密级（公开/内部）与可见范围。
3. 系统上传文件，生成草稿文档与 V1 版本，状态为"草稿"。
4. 用户在"我的文档"中点击"提交归档"，系统展示归档确认页（分类、密级、可见范围、审批人）。
5. 用户确认提交，系统创建"文档归档审批"实例与首节点任务，文档状态变为"审批中"。
6. 审批通过后，文档状态变为"已归档"，按可见范围可被检索；发起人收到通知。

**异常与分支：**

- 1a 文件类型不允许：拒绝并提示允许的类型清单。
- 1b 文件超过 50 MB：拒绝并提示压缩或拆分。
- 2a 选择"敏感"密级：跳转"敏感文档归档审批"，需额外填写敏感说明与知悉范围。
- 5a 审批被退回：文档状态变为"被退回"，发起人可修改后重新提交，生成新轮次。
- 5b 审批被驳回：文档保持草稿状态，可修改后重新发起。

**后置条件：** 文档与版本落库；审批实例生成；上传与提交行为写入审计日志。

**业务规则：** 未归档文档默认仅本人与文档管理员可见；归档前必须完成密级与可见范围设置；同一分类下标题重复时提示改名。

### UC-005 预览与下载（含水印）

| 项目 | 内容 |
| --- | --- |
| 用例编号 | UC-005 |
| 参与者 | 全部内部角色 |
| 优先级 | P0 |
| 关联需求 | FR-DOC-005、FR-DOC-006、FR-AUD-002、FR-PERM-003 |
| 前置条件 | 用户对文档具备查看或下载权限 |
| 触发条件 | 用户在详情页点击"预览"或"下载" |

**主流程：**

1. 用户点击预览或下载，系统校验会话、功能权限、密级与文档授权。
2. 校验通过后，系统读取文件流：预览走转换服务，下载走流式输出。
3. 敏感文档在输出前添加水印（姓名、学工号、时间）。
4. 系统写入下载或预览日志，包含文档编号、版本、操作人、IP、结果。
5. 浏览器展示预览内容或触发文件下载。

**异常与分支：**

- 1a 无权限：返回 403，页面提示"无权访问，可申请权限"，记录越权尝试。
- 1b 授权已过期：提示"授权已到期"，提供续期申请入口。
- 3a 水印服务异常：中止输出并告警，不得输出无水印原件。
- 4a 日志写入失败：中止下载并提示稍后重试，保证"无日志不下载"。

**后置条件：** 下载记录可查；文件未被复制到静态目录。

### UC-006 版本更新与回滚

| 项目 | 内容 |
| --- | --- |
| 用例编号 | UC-006 |
| 参与者 | 文档管理员、部门负责人 |
| 优先级 | P0 |
| 关联需求 | FR-DOC-009、FR-DOC-017、FR-AUD-002 |
| 前置条件 | 用户具备编辑权限；文档未被归档或已取消归档 |
| 触发条件 | 用户点击"上传新版本"或"回滚" |

**主流程：**

1. 用户选择新文件并填写变更说明。
2. 系统校验文件后保存为 V(n+1)，保留旧版本，更新文档当前版本指向。
3. 文档详情展示版本列表（版本号、上传人、时间、说明、大小）。
4. 用户选择历史版本点击"回滚"，系统以历史版本内容生成新的 V(n+2)，并记录回滚来源。
5. 系统通知文档关注人与相关审批人（如已归档文档需重新审批）。

**异常与分支：**

- 2a 文件与上一版本完全相同（哈希一致）：提示"内容未变化"，不生成新版本。
- 4a 文档处于"审批中"：禁止回滚，提示先撤回或等待审批结束。
- 4b 回滚至已标记"作废"的版本：需二次确认并填写理由。

**后置条件：** 版本记录完整；当前版本与列表一致；回滚行为可追溯。

### UC-008 文档级授权

| 项目 | 内容 |
| --- | --- |
| 用例编号 | UC-008 |
| 参与者 | 文档管理员、部门负责人 |
| 优先级 | P0 |
| 关联需求 | FR-PERM-003、FR-PERM-007、FR-PERM-009、FR-PERM-011 |
| 前置条件 | 授权人对文档具备管理权限；被授权人在授权人数据范围内或已获跨部门授权资格 |
| 触发条件 | 用户在文档详情点击"授权" |

**主流程：**

1. 用户选择授权对象（人员/角色/部门），勾选权限项（查看/下载/编辑），设置到期时间与用途。
2. 系统校验：授权对象有效、权限项不超出授权人自身权限、期限不超过 365 天。
3. 若属敏感权限（敏感文档、跨部门、期限超过 90 天），系统生成"权限调整审批"实例，授权暂不生效。
4. 审批通过后，系统写入授权记录，状态"生效"，被授权人收到通知。
5. 授权记录出现在文档详情与权限台账，到期前 7 天提醒。

**异常与分支：**

- 2a 授权对象为本人：拒绝，提示"不能为本人授权"。
- 2b 超出数据范围：拒绝，提示走"权限申请"。
- 3a 审批被驳回：授权记录状态"已驳回"，不生效。
- 5a 到期未续期：自动失效，被授权人访问被拒绝并收到到期通知。

**后置条件：** 授权记录与审批单关联；台账可查；变更写入审计日志。

### UC-009 权限调整审批

| 项目 | 内容 |
| --- | --- |
| 用例编号 | UC-009 |
| 参与者 | 部门负责人、审批人、院系领导 |
| 优先级 | P0 |
| 关联需求 | FR-PERM-005、FR-PERM-002、FR-PERM-006、FR-APR-013 |
| 前置条件 | 存在待审批的权限调整申请；审批人具备该事项审批权 |
| 触发条件 | 授权申请提交或权限申请通过初审 |

**主流程：**

1. 系统生成"权限调整审批"实例，展示申请人、授权对象、权限项、期限、用途与风险提示。
2. 审批人查看申请详情与申请人历史授权情况。
3. 审批人选择同意、退回或驳回，填写意见。
4. 同意且流程结束时，系统自动写入授权并通知申请人；退回则修改后重提；驳回则终止。
5. 系统记录审批轨迹，权限台账标注"审批单号"。

**异常与分支：**

- 3a 审批人发现申请超出必要范围：退回并注明建议范围。
- 4a 授权写入失败：实例标记"待补偿"，告警并支持重试，避免"审批通过但无权限"。
- 4b 同一对象重复授权：系统合并展示，提示"已有相同授权"，避免重复。

**后置条件：** 授权生效或申请终止；审批与授权记录互相可追溯。

### UC-011 配置审批模板

| 项目 | 内容 |
| --- | --- |
| 用例编号 | UC-011 |
| 参与者 | 系统管理员 |
| 优先级 | P0 |
| 关联需求 | FR-APR-001、FR-APR-002、FR-APR-003、FR-SYS-004 |
| 前置条件 | 管理员已登录；具备模板配置权限 |

**主流程：**

3. 配置流程节点：选择串行/会签/或签，设置审批人来源（指定人/角色/部门负责人/上级）、时限与超时提醒。
4. 配置规则：是否允许撤回、退回节点范围、是否允许加签、抄送人。
5. 管理员保存并预览，系统校验节点完整性与审批人可达性（角色下是否有成员）。
6. 管理员启用模板，模板版本号自增，新发起实例使用新版本。

**异常与分支：**

- 3a 审批人角色下无成员：保存被拒绝，提示先配置角色成员。
- 4a 节点超过 5 级：提示精简，避免流程过长（可配置上限）。
- 6a 修改已启用模板：生成新版本，不影响在途实例。

**后置条件：** 模板生效；版本记录可查；变更写入审计日志。

### UC-014 撤回、催办、转办与加签

| 项目 | 内容 |
| --- | --- |
| 用例编号 | UC-014 |
| 参与者 | 发起人、审批人 |
| 优先级 | P0（撤回、催办）/ P1（转办、加签） |
| 关联需求 | FR-APR-010、FR-APR-011、FR-APR-012 |
| 前置条件 | 实例处于流转中；操作人具备对应身份 |
| 触发条件 | 发起人点击"撤回"或"催办"；审批人点击"转办"或"加签" |

**主流程：**

1. 撤回：发起人点击撤回，系统校验首节点未处理，撤回后实例状态"已撤回"，任务关闭，通知已处理的审批人。
2. 催办：发起人对停滞任务点击催办，系统记录催办次数并通知当前处理人；超时后同时通知部门负责人。
3. 转办：审批人选择接收人并填写原因，系统关闭原任务、生成新任务，轨迹记录转办关系。
4. 加签：审批人选择加签人员（不超过 3 人），系统生成并行子任务，原审批人选择是否继续参与。

**异常与分支：**

- 1a 首节点已处理：撤回按钮不可用，提示"流程已开始处理"。
- 2a 同一任务 24 小时内已催办 3 次：提示稍后再试，避免骚扰。
- 3a 接收人无该事项审批权限：允许转办但提示风险，要求管理员确认（可配置）。
- 4a 加签人数超限或环节不允许加签：拒绝并提示。

**后置条件：** 操作全部记录在审批轨迹与审计日志。

### UC-021 权限到期自动回收
