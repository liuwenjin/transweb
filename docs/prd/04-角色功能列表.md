# 4 角色的功能列表

## 4.1 说明

本章按角色列出可用功能，功能编号与第 5 章需求总表一一对应。"边界"列说明该角色在使用该功能时的数据范围与限制条件；未列出的功能默认不可见，菜单与按钮按权限动态渲染，接口层同步校验。

功能可见性规则：

1. 菜单按"是否具备任一子功能权限"显示，无权限的菜单不出现。
2. 按钮按功能权限与文档状态双重控制，例如"审批"按钮仅在任务状态为"待处理"且当前用户为处理人时出现。
3. 直接输入 URL 访问无权限页面时，返回统一的无权限提示页，不暴露数据内容。

## 4.2 院系领导（LEADER）

定位：掌握全院资料与审批全局，做决策与终审，不承担日常录入与维护。

| 功能 | 编号 | 说明与边界 |
| --- | --- | --- |
| 工作台 | FR-PORTAL-001 | 查看待我审批、全院文档概览、近期办结事项 |
| 全院文档检索与预览 | FR-DOC-007、FR-DOC-005 | 可按分类、部门、密级筛选；仅预览，不提供编辑入口 |
| 文档下载 | FR-DOC-006 | 公开与内部文档可直接下载并留痕；敏感文档需具备密级权限或经授权 |
| 审批待办与已办 | FR-APR-005、FR-APR-006 | 处理分配给自己的终审任务；可查看本人历史审批 |
| 同意 / 退回 / 驳回 | FR-APR-007、FR-APR-008、FR-APR-009 | 同意可填写意见；退回需选择退回节点与理由；驳回需填写理由并终止流程 |
| 审批进度查询 | FR-APR-013 | 查看全院审批实例的当前环节、处理人与耗时 |
| 统计看板 | FR-PORTAL-004、FR-APR-016 | 文档总量、分类分布、审批办结率、平均时长、超时事项 |
| 权限台账（只读） | FR-PERM-006 | 查看谁对哪些资料拥有何种权限，不支持修改 |
| 审计报表（只读） | FR-AUD-005 | 查看登录与关键操作统计，不展示文档正文 |
| 公告查看 | FR-PORTAL-005 | 查看系统公告与制度通知 |

## 4.3 文档管理员（DOCADMIN）

定位：院系资料的日常管理者，负责"资料进得来、分得清、找得到、管得住"。

| 功能 | 编号 | 说明与边界 |
| --- | --- | --- |
| 分类目录维护 | FR-DOC-001 | 新增、重命名、排序、停用分类；停用前须先迁移或归档目录下文档 |
| 文档上传与批量上传 | FR-DOC-002、FR-DOC-003 | 支持 PDF、Word、Excel、PPT、TXT、Markdown、图片、压缩包；单文件不超过 50 MB |
| 文档属性与密级设置 | FR-DOC-004 | 设置标题、分类、归属部门、标签、密级、可见范围、有效期 |
| 在线预览 | FR-DOC-005 | PDF、图片、文本、Office 转换预览；不支持格式提供下载查看 |
| 下载与水印 | FR-DOC-006 | 敏感文档下载默认添加"姓名 + 时间"水印，并记录审计日志 |
| 文档检索与高级筛选 | FR-DOC-007、FR-DOC-008 | 按标题、编号、标签、上传人、时间、密级、部门组合筛选 |
| 版本管理 | FR-DOC-009 | 查看历史版本、下载历史版本、回滚到指定版本；回滚生成新版本而非覆盖 |
| 归档与取消归档 | FR-DOC-010 | 归档后文档只读；取消归档需填写理由并留痕 |
| 回收站与恢复 | FR-DOC-011、FR-DOC-012 | 删除进入回收站保留 30 天，可恢复；彻底删除需二次确认并留痕 |
| 编辑、重命名、移动、复制 | FR-DOC-013、FR-DOC-014 | 移动跨部门需具备目标部门管理权限；复制保留原密级 |
| 文档库授权 | FR-PERM-002 | 对分类或部门文档库授予查看、下载、上传、编辑权限，设置到期时间 |
| 文档级授权 | FR-PERM-003 | 对单份文档临时授权给人员或角色，须填写用途与期限 |
| 权限台账与变更记录 | FR-PERM-006、FR-PERM-009 | 查看本人发起的授权及其生效、到期、收回记录 |
| 文档操作记录 | FR-DOC-017 | 查看单份文档的上传、下载、编辑、授权、审批历史 |
| 审批记录查询 | FR-APR-013 | 查看与文档相关的审批实例与意见 |
| 回收站清理 | FR-DOC-012 | 仅系统管理员可执行彻底删除；文档管理员可发起清理申请 |

## 4.4 部门负责人（DEPTHEAD）

定位：本部门资料与事项的第一责任人，负责部门内授权审核与一级审批。

| 功能 | 编号 | 说明与边界 |
| --- | --- | --- |
| 本部门文档管理 | FR-DOC-002、FR-DOC-013、FR-DOC-010 | 仅限本部门及下级部门；不能操作其他部门文档 |
| 本部门文档检索与下载 | FR-DOC-007、FR-DOC-006 | 本部门全部文档；跨部门需被授权 |
| 本部门文档授权 | FR-PERM-002、FR-PERM-003 | 可在本部门范围内授权，超出范围需提交权限申请 |
| 本部门权限申请审批 | FR-PERM-004、FR-PERM-005 | 审批本部门成员对敏感资料或跨部门资料的权限申请 |
| 发起审批 | FR-APR-004 | 代表部门发起事项，如部门资料归档、对外提供材料 |
| 处理待办 | FR-APR-005、FR-APR-007 至 FR-APR-009 | 处理本部门相关审批任务 |
| 本部门统计 | FR-PORTAL-004 | 本部门文档数量、下载情况、审批办理时长 |
| 本部门成员权限查看 | FR-PERM-006 | 查看本部门成员的角色与授权，不可修改角色 |
| 部门审批记录 | FR-APR-013 | 查看本部门发起的审批与处理记录 |

## 4.5 审批人（APPROVER）

定位：被指定处理具体审批任务的人员，权限来自任务分配而非固定角色。

| 功能 | 编号 | 说明与边界 |
| --- | --- | --- |
| 待办列表 | FR-APR-005 | 仅显示分配给本人且状态为"待处理"的任务，按紧急度与时限排序 |
| 已办列表 | FR-APR-006 | 本人已处理任务，可按时间、事项类型、处理结果筛选 |
| 审批详情 | FR-APR-013 | 查看表单内容、附件、历史意见、当前环节与剩余时限 |
| 同意 | FR-APR-007 | 可填写意见、添加附件；会签节点需全部同意才流转 |
| 退回 | FR-APR-008 | 退回至发起人或指定前序节点，必须填写退回理由 |
| 驳回 | FR-APR-009 | 终止流程，必须填写驳回理由，发起人可修改后重新发起 |
| 转办 / 加签 | FR-APR-011 | 转办需说明原因；加签仅限模板允许的环节，且不超过 3 人 |
| 催办 | FR-APR-012 | 对停滞环节发起催办，系统向当前处理人发送通知并记录 |
| 撤回（发起人） | FR-APR-010 | 仅发起人可撤回，且首个节点尚未处理时有效 |
| 打印 / 导出审批单 | FR-APR-015 | 导出带水印 PDF，含表单、意见与流转记录 |
| 审批记录查询 | FR-APR-013 | 查询本人参与过的审批全流程记录 |
| 消息通知 | FR-PORTAL-003 | 新任务、退回、催办、超时提醒 |

## 4.6 教职工 / 发起人（STAFF）

定位：系统使用主体，查询资料、上传本人材料、发起与跟踪审批。

| 功能 | 编号 | 说明与边界 |
| --- | --- | --- |
| 工作台 | FR-PORTAL-001 | 我的待办、我的文档、我发起的审批、通知 |
| 文档检索与预览 | FR-DOC-007、FR-DOC-005 | 仅公开、内部及被授权文档；敏感文档不可见 |
| 文档下载 | FR-DOC-006 | 仅允许下载有权限文档；敏感文档需审批通过 |
| 上传文档 | FR-DOC-002 | 上传至"我的文档"，默认仅本人与文档管理员可见 |
| 编辑与删除本人文档 | FR-DOC-013、FR-DOC-012 | 已归档文档不可编辑；删除进入回收站 |
| 提交归档 | FR-DOC-010、FR-APR-004 | 选择分类、密级与可见范围后提交归档审批 |
| 发起审批 | FR-APR-004 | 从模板选择事项，填写表单、上传附件、提交 |
| 撤回与催办 | FR-APR-010、FR-APR-012 | 撤回限首节点未处理；催办限流程停滞超过设定时限 |
| 审批进度查询 | FR-APR-013 | 查看本人发起的审批进度、意见与结果 |
| 权限申请 | FR-PERM-004 | 申请查看、下载、编辑某分类或某份文档，填写用途与期限 |
| 我的文档 | FR-DOC-016 | 按状态（草稿、审批中、已归档、被退回）管理本人文档 |
| 消息通知 | FR-PORTAL-003 | 审批结果、退回、授权到期、系统公告 |
| 个人设置 | FR-PORTAL-007 | 通知方式、默认分类、每页条数 |

## 4.7 系统管理员（SYSADMIN）

定位：系统的配置与运维责任人，保障组织、角色、模板、参数与数据安全。

| 功能 | 编号 | 说明与边界 |
| --- | --- | --- |
| 部门管理 | FR-SYS-001 | 维护部门层级、负责人、排序与状态 |
| 用户管理 | FR-SYS-002 | 查看用户、分配角色、设置密级权限、停用与恢复 |
| 角色管理 | FR-SYS-003 | 维护角色、权限编码、数据范围；内置角色不可删除 |
| 审批事项与模板配置 | FR-APR-001 至 FR-APR-003 | 配置事项类型、表单字段、审批环节、审批人、时限、退回规则 |
| 字典与参数 | FR-SYS-004、FR-SYS-005 | 维护文档分类标签、密级、通知模板、会话超时、文件大小限制等 |
| 组织同步 | FR-SYS-006 | 查看最近同步时间与结果，支持手工触发与差异对比 |
| 数据导入与初始化 | FR-SYS-008 | 按模板导入部门、人员、历史文档索引；导入前校验并生成报告 |
| 公告管理 | FR-PORTAL-005 | 发布、撤回公告，设置可见范围 |
| 审计日志查询 | FR-AUD-005 | 查询登录、文档、授权、审批日志；可导出 |
| 备份与恢复 | FR-AUD-008 | 配置备份策略、执行手工备份、查看备份记录、执行恢复演练 |
| 系统健康检查 | FR-SYS-007 | 查看数据库连接、磁盘空间、任务队列、最近错误 |
| 公告与通知模板 | FR-PORTAL-005 | 维护站内信与邮件模板 |

> 边界：系统管理员不默认具备文档正文读取权限；因排障需要临时读取时，须通过"临时授权"流程并记录原因，日志保留可查。

## 4.8 审计员（AUDITOR）

定位：独立核查权限与操作记录，只读、不参与业务。

| 功能 | 编号 | 说明与边界 |
| --- | --- | --- |
| 登录日志查询 | FR-AUD-001、FR-AUD-005 | 按账号、时间、IP、结果筛选；不可修改或删除 |
| 文档操作日志查询 | FR-AUD-002、FR-AUD-005 | 查看上传、下载、预览、编辑、删除、归档记录 |
| 授权变更日志查询 | FR-AUD-003、FR-AUD-005 | 查看授权人、被授权人、范围、期限、审批单号 |
| 审批留痕查询 | FR-AUD-004、FR-AUD-005 | 查看各环节处理人、意见、时间与结果 |
| 审计导出 | FR-AUD-006 | 导出 CSV / Excel，导出行为本身记录审计 |
| 权限台账查看 | FR-PERM-006 | 查看全院权限分布与到期情况 |
| 统计报表 | FR-PORTAL-004 | 只读查看登录、下载、审批统计 |
| 异常告警确认 | FR-AUD-009 | 查看异常登录、越权尝试、大批量下载告警并标记处理结果 |

> 边界：审计员不可下载文档正文，不可查看敏感文档内容，不可修改任何业务数据。

## 4.9 学校统一身份认证（IDP，外部系统）

| 能力 | 编号 | 说明 |
| --- | --- | --- |
| 认证与票据校验 | FR-AUTH-001 | 提供登录页跳转、票据校验接口，返回学工号与姓名 |
| 单点登出 | FR-AUTH-004 | 接收 OA 登出请求，使全局会话失效 |
| 组织与人员同步 | FR-SYS-006 | 按约定提供部门、人员、状态数据（接口或文件） |
| 账号状态通知 | FR-AUTH-007 | 离职、调岗、停用事件通知或供定时拉取 |

## 4.10 角色上线顺序

| 阶段 | 开放角色 | 目的 |
| --- | --- | --- |
| 试点第 1 周 | STAFF、DOCADMIN、APPROVER | 走通"上传—归档—审批—下载"主链路 |
| 试点第 2 周 | DEPTHEAD、LEADER | 验证部门授权与终审 |
| 试点第 3 周 | AUDITOR、SYSADMIN | 验证审计与配置能力 |
| 上线 | 全部角色 | 全院推广 |
