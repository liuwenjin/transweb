激活功能模块
按优先级配置以下项目；点击标题展开配置概述与说明
01 root 管理账号 最高优先级
配置概述

最高优先级：先取得管理端登录凭据，再配置算力、支付与登录验证码。

transweb root accessKey
transweb root accessKey --json

transweb root accessKey 输出 root 管理账号与万能验证；默认 transweb / transweb$harness。登录选「验证码登录」，验证码填万能验证。

02 算力供应方
配置概述

一个算力供应方对应一个 apiName；至少配置 1 个。

transweb api add <apiName> \
  --url <url> \
  --key <apiKey>

apiName 是自定义接入名（示例 dmxapi，也可以叫 深度求索），后续模型通过 --api-name 引用；--key 写入 .env 的 API_KEY_*，common.js 只保留引用。

03 model
配置概述

模型挂在算力供应方下；至少配置 1 个，并设为默认模型。

transweb model add <model> \
  --api-name <apiName> \
  --input <rate> --output <rate> \
  --context <context> --from <国内|国外>

transweb default model --model <model>

至少 1 个，包含 apiName、费率与 from。费率 = 积分与 token 的比例：1 个 AI token 对应多少积分，输入 / 输出分别计费；from 填 国内 或 国外，context 为上下文 token 数。配置后执行 transweb default model 设为默认。

04 微信支付
配置概述

正式收款前配置微信支付 APIv2 参数；至少完成必填项。

transweb wxpay set <参数> <值>
transweb wxpay check

必填 WX_PAY_APP_ID、WX_PAY_MCH_ID、WX_PAY_APP_KEY（32 位 APIv2 密钥）、WX_PAY_ORDER_URL、WX_PAY_QUERY_URL；按需 WX_PAY_APP_SECRET、WX_PAY_NOTIFY、WX_PAY_APP_ID001 / SECRET001。用 transweb wxpay set 写入、wxpay check 校验；安装生成的 APP_KEY 是随机值，正式收款前替换为商户平台密钥。

05 登录验证码
配置概述

用户登录 / 注册的短信验证码服务；未配置时手机验证码不可用。

transweb env set SEND_MESSAGE_API_KEY <key>

用户登录 / 注册的短信验证码服务 API Key：SEND_MESSAGE_API_KEY（螺丝帽短信）。用 transweb env set SEND_MESSAGE_API_KEY <key> 配置；未配置时手机验证码登录 / 注册不可用。

展开各配置项查看命令；完成后用 transweb api list、transweb model list、transweb default list 检查 AI 配置，微信支付用 transweb wxpay check，短信 Key 用 transweb env get SEND_MESSAGE_API_KEY 检查。API / model 同名配置已存在时加 --force。transweb root accessKey 与 transweb env get ADMIN_ACCOUNT / POWER_ADMIN 读取同一份 .env；修改后需 transweb restart 生效。

部署提示
  • 开源地址：github.com/liuwenjin/transweb
  • 上线前安全：务必执行 transweb admin hide，避免后台入口（admin.html / initAdmin.html）暴露到公网；公网部署再设 TRANSWEB_DISABLE_ADMIN=1 兜底。
  • 初始化页面：初始化完成前 /initAdmin.html 自动可访问，初始化完成后自动返回 404；再次进入后台执行 transweb admin show。
  • 首次初始化：自动安装应用依赖（约 543 个包）并下载 MongoDB 6.0.x（约 58MB）。
  • 数据目录：服务目录默认 ~/.transweb-service，升级 npm 包不会丢失数据。
  • 局域网访问：其他设备可直接访问 transweb status 里显示的地址。

隐私政策

最近更新：2026 年 11 月

我们收集哪些信息

账号标识（登录方式与昵称）、你主动上传的资料，以及保障服务可用所必需的运行日志，例如访问时间、设备与浏览器类型、错误信息。我们不会为了广告投放而追踪你的浏览行为，也不会将上述信息用于本政策未说明的用途。

资料如何被使用

你上传的资料只会用于构建并支撑属于你自己的数字员工。解析结果仅在你的账号范围内可见，用于回答你的提问；我们不将其用于公共模型训练，也不出售。为完成当次请求，必要内容会传递给模型 / 云服务商（见「第三方服务」）。

存储与安全

通过 HTTPS 访问时，资料传输使用 TLS 加密；存储阶段按账号隔离并施加访问控制。运行日志仅保留排障所必需的周期，到期自动清理。

第三方服务

内容的解析与问答依赖底层模型和云基础设施服务商。我们仅向其传递完成当次请求所必需的内容，并要求其承担同等的保密义务。

你可以做什么

你可以随时查看、导出或删除自己的资料与数字员工。删除后，对应的解析结果与生成记录会同步清除。如果你希望注销账号，可通过「联系我们」提出，我们会在核实身份后处理。

未成年人

本服务面向具备完全民事行为能力的用户。若你未满 18 周岁，请在监护人的陪同下阅读本政策并使用本服务。

政策更新

本政策如有实质性变更，我们会在页面显著位置提示，并同步更新顶部的更新日期。继续使用本服务，即表示你接受更新后的政策。
