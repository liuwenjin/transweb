为什么单文件架构比传统云端工作流更有优势？

单文件意味着零运维、零调优、易存档、极速分发。你的工作流资产可以像文档一样保存在本地，随用随开，永不担心因服务端宕机而中断业务。

如何导入或分享工作流？

支持一键导出 HTML 文件，团队成员双击即可运行，也可以放回静态服务器继续使用。

使用需要付费吗？

功能完全免费。引擎本身 MIT 开源，无需注册或订阅，打开网页即用。

支持自己配置 API Key 吗？

支持配置。可使用内置模型，也支持调用大模型时需填入你自己的 API Key，Key 只保存在你的浏览器本地，不会上传到任何服务器。

支持哪些模型？

支持兼容 OpenAI 接口的主流模型，可在 Skill 节点中灵活切换。

我可以将 Trans-Workflow 嵌入我们现有的系统或产品中吗？

当然！Trans-Workflow 采用极简的单文件架构与 MIT 开源协议。无论是作为内部工具链的基础设施，还是集成到现有 SaaS 产品中，你都可以自由定制与商业化使用。
